## 两种把手位置（同页对比）

页面默认显示“把手对比”，保留原有五种图标方案；不用打开新页面。

1. 顶部居中：当前位置，也是首选建议；避开名称与操作区。
2. 图标左侧：竖向三点紧邻 Logo 并居中对齐，水印模式下位于项目名称左侧。

只保留把手 1、2，移除 3–6。顶部居中使用横向三点（16×4px 图形、28×24px 操作区）；图标左侧使用竖向三点（4×16px 图形、24×28px 操作区），点径均为 2.4px。默认透明，鼠标悬浮显示与卡片同色系的轻淡背景色，同时点变亮；不加阴影或光圈。键盘操作保留焦点提示。

顶部居中保留 28px 顶部间距；图标左侧不另占顶边，保持常规 18px 内边距。卡片最小高度 326px。对比区双列展示，窄屏改为单列。

两种把手默认分别展示 localPlay、RunDock、看剧鸭三种不同图标。每种把手都有独立的“项目图标”选择，可在五个示例项目间切换，互不影响；“多个项目”恢复对照，“看整组”展示全部五个项目。卡片图标设计、底色和状态仍统一切换。当前只演示位置、按下和键盘点击反馈，不执行真实拖拽排序。暂选不写入产品配置。

## 设计约束

- 沿用 RunDock 的色彩和字体：#101216 背景、#191c22 表面、#eef0f4 正文、#acb4c0 次要文字、#4b83e6 操作色；背景 Logo 根据方案降低饱和度与透明度。
- 同一套示例项目、状态和功能，比较图标构图而不是换色；并排对比可统一换项目、底色、状态、长名称及无图标。
- 原色资源均为现有本地项目图标副本，仅供内部设计评审，不上传、不重新授权。
- 依据 frontend-design 区分背景构图，依据 better-ui 做间距、光学对齐、减少动画偏好与触控反馈。1 保留标题图标，2–5 均使用背景图标，不改变信息与操作的位置；无图标时不绘制大幅占位图。
- Demo 独立挂载，不引用应用状态、HTTP 客户端或原生 IPC；所有按钮只反馈示例，不启动、停止或发布真实项目。
- 暂选只保留在当前页面内存，刷新即清除；用户回聊天确认后才能实施。
- 本次不进一步修改或撤回上一轮正式源码改动，不重启后台。五种候选都只在此目录。
