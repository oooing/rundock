## 修复

- 上传型发布在改版本、提交和构建安装包之前检查实际推送地址的分支。远端领先或分叉时，以 `branch_behind` 停止。新建分支和本地领先允许继续；仅本地保存不联网。
- 获取缺少的远端对象时，不改工作区、暂存区、跟踪引用、Tag 或 `FETCH_HEAD`。不同 fetch/push 地址分别处理，以实际 push 地址为准。
- 检查后远端仍可能发生新提交，正式推送继续由 Git 的正常快进规则保护，不自动强推，也不自动合并项目代码。
- 发布面板在检查、提交准备、排队、执行和重试期间禁止关闭；右上角关闭按钮同步禁用。失败、成功或取消后恢复关闭。等待偏好保存之后再次核查忙碌状态，防止异步关闭越过发布状态变化。
- Windows PowerShell 5 开发启动器提前保留后台进程句柄，避免 `HasExited` 后读取到空退出码，将请求重启的退出码 75 误判为停止整个开发环境。
