# 纯本地构建与持久产物

## 目标与边界

用户只想取得本机安装包时，不应先提交代码、改版本或创建 Tag。
本地/云端是发布页内的构建方式，不新增一级标签；新项目默认云端，显式选择按项目保存。
本地发布与云端共用目标、版本、文件和检查视图。勾选“仅构建当前版本”时，
使用当前工作文件的隔离快照和当前版本，不展示提交/版本升级操作。
正式发布、保存进度及其自动保存偏好不变；不修改外部项目配置。

领域职责：releaseconfig 提供项目声明；publisher 冻结、执行和取消构建；
store 保存任务与产物清单；受限本机 API 按任务 ID 提供下载/打开目录；
前端只负责选择目标、状态和下一步操作，不决定 Git 或远程权限。

数据流：已登记项目 → 配置指纹及可构建目标 → 幂等请求 → 当前源码快照
→ 已声明的检查/构建/打包/验证 → 原子保存与哈希清单 → 成功 → 获取产物。
构建与正式发布分流，不在现有提交函数中增加一组“跳过 Git”条件。
有 Git 的项目按当前工作文件取快照，无 Git 的项目也可构建；暂存状态不变。
项目声明的命令不是安全沙箱：隔离快照防止普通构建写回源文件，但不能约束
用户命令中的绝对路径、网络及外部工具。依赖安装仍由项目命令负责。

## 编码前的失败清单

- 错误进入提交/版本/Tag/上传/部署路径；客户端伪造远程动作。
- 配置迟到、版本源冲突、重复点击、同项目并发、取消先于执行注册。
- 复制源码时文件变化、路径越界、符号链接/目录联接、依赖缺失。
- 命令失败、超时、取消、进程退出、磁盘不足；半成品被当成成功。
- 产物未声明、缺失、空文件、验证失败、同名冲突、复制期间改变。
- Windows 读取句柄阻止整目录移动；保存中崩溃留下部分文件或不完整清单。
- 成功后快照清理、重启、清单或产物被删除/篡改；旧记录假装可下载。
- 其他网页读取本地文件/触发命令，任意路径或其他任务产物越权。
- 本地重试误调用正式 Git 重试，或切换入口改变正式发布偏好。
- 构建方式被误当成独立导航；切换模式或进入设置丢失已接受的后台任务。
- 没有 Git 或当前配置损坏时，发布视图遮住纯本地构建及历史产物。

## 故障与恢复

任务成功以产物验证并持久保存为条件，不以命令退出码为唯一依据。
按实例数据目录/任务/目标独占创建保存目录，清单关联 SHA-256。
文件与清单写完、同步并校验后，数据库登记事务一次公开全部已验证产物；
登记前下载及打开目录 API 不可见，不依赖移动整个目录。
下载/打开操作重新核验所属任务、清单、普通文件、大小与哈希，不接受任意路径。
已完成产物不依赖临时源码；中断任务明确标记，可由用户开始新构建，不自动重跑。
保留命令错误上下文，采用已有诊断输出截断/脱敏边界，不记录凭据。
纯本地任务日志只写实例数据库，不写原项目的诊断目录，避免改变源码与 Git 状态。
文件及清单写完后丢失数据库登记时，重启按已捕获的任务/目标/文件哈希核验并补登记；
不会因找回产物就把中断任务变为成功。仅清理已记录且归属已验证的临时快照，
无法证明归属或含目录链接的目录保留并记录原因，不扫描系统 Temp 猜测删除。
当前配置损坏不遮住历史产物；正式发布历史与纯本地历史分开，旧路由也校验来源。
Windows 读取使用扩展路径；已有目录仅接受完全相同且通过验证的清单，不覆盖旧文件。
原因：整目录重命名在普通只读文件句柄存在时也会 AccessDenied，不能假定它表示 ACL 拒绝。
部分保存保守保留为不可见；不能把权限/占用/路径错误误报为清单冲突。终态日志返回最新 500 条，
防止重新打开较长任务时丢失最后的错误；正式发布的日志分页合同不变。

## 验收与回滚

先建立实际 HTTP/SQLite + Vue/浏览器端到端脚本，结束时运行并保存 JSON、截图、trace。
验证干净/未提交/已暂存/无 Git 的构建、配置变化、幂等、失败/取消、产物验证、
重启恢复、下载哈希、本机来源与路径限制，并证明源文件、HEAD、暂存区、Tag 不变。
正式发布保持原入口与合同；本次不提交、推送、公开发布、安装或替换正式版。
新表为增量迁移，无存量数据搬迁；回滚代码不删除已有任务或产物。

App 说明保持两句：在本机生成安装包，不提交代码、不创建版本、不上传。
选目标 → 开始构建 → 打开产物目录/下载。
