# 保留项目退出后的更新状态

## 问题

静默安装完成后选择“保留项目”退出，旧后台仍托管运行中的项目。再次打开可以加载新版窗口，但后台仍是旧版。过去把这两种状态都显示成“下次启动生效”，使用户误以为安装未生效或需要反复退出。

## 处理

- 窗口仍是旧版：显示“新版已安装 / 等待完整重启”，说明保留项目退出只更新窗口。
- 窗口已更新、后台仍旧：显示“后台待更新 / 窗口已更新”，明确项目继续运行。
- 后台版本不可确认：显示未知状态，不冒充完成，不提供无法确认的立即生效操作。
- 窗口和后台均确认达到目标版本，且后台不落后于当前窗口：归档已完成的 staged 记录，清除待生效提示。未完成的项目恢复仍保留。
- 打开详情时重新核对，详情可见时轮询；关闭详情后停止轮询。状态读取只查询后台，不安装、不停止、不恢复项目。
- “立即生效”仍先列出将重启的项目，二次确认后才执行原有更新流程。退出时保留项目的行为不变。

持久化归档沿用原有恢复锁、原子写入和快照复查，防止慢查询覆盖新操作。新版窗口不能仅凭版本号相同就假定后台已更新。

## 验证

- `scripts/tests/app-update.test.mjs`：运行真实状态层，覆盖保留旧后台、版本无法确认、提示清除、显式停止确认及旧流程回归。
- `src-tauri/src/update_transaction.rs`：真实本机模拟服务和隔离目录，验证版本比较、只读状态请求、归档与重复读取。
- `scripts/acceptance/update-activation-ui.mjs`：实际 Vue 侧栏、设置及弹窗，模拟原生 IPC，覆盖中英文、窄屏、保留项目和清除提示。

这些是源码和隔离验证，不代表已替换用户安装的客户端。实际客户端需在后续安装包含修复的版本后生效。
